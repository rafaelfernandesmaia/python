# 10 Exercícios de Lógica de Programação em Python

## Exercício 1: Par ou Ímpar
Crie um programa que leia um número inteiro e informe se ele é par ou ímpar.

## Exercício 2: Soma de Pares
Faça um programa que leia 5 números inteiros e mostre a soma dos números pares.

## Exercício 3: Maior e Menor
Leia 3 números e mostre o maior e o menor valor.

## Exercício 4: Contador de Vogais
Crie um programa que conte quantas vogais existem em uma palavra digitada pelo usuário.

## Exercício 5: Fatorial
Calcule o fatorial de um número inteiro positivo fornecido pelo usuário.

## Exercício 6: Inverte String
Escreva um programa que inverta uma string sem usar funções prontas de reversão.

## Exercício 7: Números Primos
Verifique se um número inteiro é primo ou não.

## Exercício 8: Fibonacci
Gere a sequência de Fibonacci até o N-ésimo termo, onde N é fornecido pelo usuário.

## Exercício 9: Matriz Identidade
Crie uma matriz quadrada NxN preenchida com zeros, exceto a diagonal principal que deve ser 1.

## Exercício 10: Busca em Lista
Crie uma lista com 10 números aleatórios e implemente uma função de busca binária para encontrar um valor específico.
